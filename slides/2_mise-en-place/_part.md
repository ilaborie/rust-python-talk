# La mise en place

## [PyO3](https://pyo3.rs/) + [Maturin](https://www.maturin.rs/), et on écrit du code

<!-- notes -->

- PyO3 : les bindings (les macros)
- Maturin : le build et le packaging des wheels
- Standards de fait depuis ~2020, tous deux maintenus par la même orga GitHub
- Chapitre complet : 15 min, préparation et récapitulatif compris
- Budget : résultat visé et configuration 2 min ; live-code 11 min ; résultat et sens inverse 2 min
- Le script `demo/README.md` porte les checkpoints et la bascule vers la solution ; annoncer cette limite avant d'ouvrir le terminal
