# 🐍 Python en bref

- **Souple, expressif, rapide à écrire**
- **Itération rapide** : prototypage, exploration, REPL
- **Accessibilité** : scolaire, scientifique, débutant
- **Écosystème colossal** : data, ML, web, scripting
- **Lent en pur Python** → libs natives pour la perf

<!-- pause -->

> NumPy, PyTorch, TensorFlow… déjà en C/C++.
> Et maintenant en Rust.

<!-- notes -->

- Python est **lent** (interpréteur, dynamic dispatch, GIL)
- Mais l'écosystème scientifique a contourné ça depuis 20 ans avec C/C++
- La nouvelle vague : Rust prend la place de C/C++
- Pourquoi Rust et pas C++ ? Sécurité mémoire + ergonomie de build (cargo)
