# 🦀 Rust en bref

- **Performances** : sans GC, proche du métal
- **Sûreté mémoire** : ownership, borrow checker
- **Système de types** : enums, traits, lifetimes
- **Fearless concurrency** : data race = erreur de compilation
- **Bas niveau, mais ergonomique**
